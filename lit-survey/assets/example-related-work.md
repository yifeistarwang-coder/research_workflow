# Related work 示例：预算约束下的候选筛选

以下论文及原文位置均为虚构。主干为 A（固定预算筛选）与 C（联合优化质量与成本），本例演示 agent 怎样总结其间和其后的工作。

## 固定预算下的阈值调整

B 延续 A 的候选表示和固定预算，将统一阈值改为由验证集估计的阈值。按摘要描述，它主要改变阈值的选取方式。训练与校准是否使用额外预算，还需要查看实验设置；当前不足以比较整体成本。

- **论文 B，2016，`paper-b`**：相对 A（`paper-a`），差异是阈值由验证集估计，预算设定保持不变。依据：示例摘要。阅读建议：先看本条；复现阈值选择时补读校准步骤与实验设置。

## 成本估计的替换

D 沿用 C 的联合目标，用轻量模型估计候选成本。它把 C 中统一估计的成本换成了逐候选预测值。该变化可能更贴近成本不一致的场景，但是否带来收益还取决于预测误差。

- **论文 D，2022，`paper-d`**：相对 C（`paper-c`），差异是加入逐候选成本预测，停止策略和训练目标保持不变。依据：示例方法部分 [p.3]。阅读建议：若目标场景的候选成本差异较大，补读误差分析和成本预测消融；这些部分尚未核验。
