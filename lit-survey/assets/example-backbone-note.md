## 解决什么问题

A 先固定筛选预算，再比较输出质量。C 指出，同一个预算未必适合不同输入，因此把每次选择的计算成本纳入优化目标。作者在引言中明确以 A 的预算设定作为比较起点 [p.1]。

## 核心机制

C 沿用 A 的候选表示和打分器，增加一个根据当前状态决定是否继续筛选的策略。目标函数同时包含输出损失与计算成本，二者通过权重参数平衡 [p.3]。

## 关键证据

表 2 比较 A 的固定预算与 C 的停止策略，同时报告质量和平均成本。这个比较适合判断策略是否改善二者的取舍，但表中只有一种候选规模，尚不能说明规模增大后的表现 [p.5, 表 2]。

## 与前作的关系

C 保留 A 的筛选框架，把预先给定的预算改为策略需要决定的变量。这一差异来自作者的方法说明 [p.3]。

agent 建议将 C 列为主干：理解它需要重新考虑预算如何进入问题定义。中间的 B 只调整 A 的阈值估计方法，可以先读 related work 条目。

## 遗留问题

作者说明实验按统一单位估计候选计算成本 [p.7]。实际候选的成本不同时，停止策略是否仍有效，当前实验无法回答。需要先查后续是否已有相关扩展，再判断是否值得研究。

## 给 researcher 的阅读建议

先读 A 的问题设定，再对照 C 第 3 页的目标函数，检查新增成本项改变了哪些优化变量。随后看表 2 是否覆盖自己关心的质量与成本区间。
